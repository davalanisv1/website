# 🌐 Personal Portfolio Website

A clean, responsive, and lightweight personal website built using **HTML5** and **CSS3**. This site serves as a digital hub to showcase my academic achievements, personal projects, creative hobbies, and ongoing reading list.


## 📂 Features & Sections

### 🎓 Academic & Leadership
*   **School Transcripts:** Completed coursework, GPA tracking, and academic milestones.
*   **Club Participation:** Extracurricular activities, leadership roles, and community involvement.

### 🛠️ Projects & Crafts
*   **Coding & Technical Projects:** Source code, live demos, and documentation for digital builds.
*   **Handmade Crafts:** Photo galleries and step-by-step breakdowns of physical DIY projects.
*   **Hobbies:** Dedicated spaces for personal interests, photography, or creative writing.

### 📚 Media Tracking
*   **Books Read:** A curated digital library tracking completed books, current reads, and brief reviews.
